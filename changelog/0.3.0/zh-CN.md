# alonabot-adapter-telegram 0.3.0 - 2026-11-23

### 新增

- 添加或编辑账号时，可在 WebUI「账号设置」中粘贴 Bot Token 并用 `getMe` 验证，确认机器人名称和用户名后再回填到配置；代理按 `none`、`core`、`custom` 设置生效 ([#10](https://github.com/AlonaBot/alonabot-adapter-telegram/pull/10))。
- 支持 Core v0.3.0 的 Adapter 操作目录与 `alonabot adapter instance` 调试命令。

账号设置页面需要 Core 和 WebUI v0.3.0。
