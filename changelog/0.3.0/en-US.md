# alonabot-adapter-telegram 0.3.0 - 2026-11-23

### Added

- When adding or editing an account, paste a Bot Token in WebUI's account settings page and verify it with `getMe`; the bot's name and username are shown before the token is filled into the configuration. The `none`, `core` and `custom` proxy modes apply ([#10](https://github.com/AlonaBot/alonabot-adapter-telegram/pull/10)).
- Support Core v0.3.0's Adapter action catalog and `alonabot adapter instance` debugging commands.

The account settings page requires Core and WebUI v0.3.0.
