# alonabot-adapter-telegram 0.2.0 - 2026-11-22

### 新增

- 支持语音、GIF 动画、静态贴纸、视频便笺、媒体引用流式上传及 URL 按钮。
- 增加 `file_base_url` 与聊天标题，提供 14 个类型化动作、输入状态、私聊流式草稿助手及按序分批撤回。
- 提供 7 类服务消息事件与载荷 Schema、服务消息过滤及成员通知去重。
- 支持自动/手动分域命令菜单与按语言设置、读取、删除，保留平台错误和上次成功菜单；分域菜单控制需要 Core v0.2.0。

### 修复

- GIF 引用与内联上传使用 `.gif` 文件名及 `image/gif` 类型；其他上传保留来源 MIME 和文件原名。

### 发行与升级

- 提供五个平台 `.tar.gz` 归档，包含 Windows amd64；源码压缩包由 GitHub 提供，移除独立 `release.json`、签名与公钥资产。
- SDK 与打包器固定到已审查的 Core 提交 `2dbbded7184f`（`v0.1.2-0.20261122021903-2dbbded7184f`），包含 v0.2.0 的归档安装流程；本组件采用 MIT 许可证。
- 安装或更新本版前先升级 Core v0.2.0。替换前停止组件并备份数据，保留相同组件 ID、来源与数据目录；历史旁车在 Core 与 WebUI 验证完成后清理。
