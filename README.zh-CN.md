# AlonaBot Telegram 适配器

[English](README.md)

通过 long polling 接入 Telegram Bot，提供媒体、类型化动作与事件、分域命令菜单。

## 快速使用

使用 Core v0.2.0 或更高版本，在运行 Core 的机器上执行：

```fish
alonabot install --source AlonaBot/alonabot-adapter-telegram --yes
```

在 Core 添加 Telegram 账号并配置 Bot Token。
