# AlonaBot Telegram Adapter

[简体中文](README.zh-CN.md)

Connect Telegram bots through long polling, with media, typed actions and events, and scoped command menus.

## Quick start

Use Core v0.3.0 or later. On the machine running Core:

```fish
alonabot install --source AlonaBot/alonabot-adapter-telegram --yes
```

Add a Telegram account in Core and configure its bot token.
When adding an account in WebUI, open **Account settings** to verify the Bot Token before saving.
